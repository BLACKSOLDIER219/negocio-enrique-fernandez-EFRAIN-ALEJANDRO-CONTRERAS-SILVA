# Conflicto controlado de Git

1. En dos ramas diferentes se modifica la misma línea del README.md con textos incompatibles.
2. Al integrar la segunda rama, Git señala un conflicto porque no puede elegir automáticamente entre ambas versiones.
3. Se edita el archivo para conservar el contenido correcto, se eliminan los marcadores del conflicto, se prueba el resultado y se confirma la resolución en un commit antes de finalizar la integración.
